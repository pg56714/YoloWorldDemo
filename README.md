# YoloWorldDemo

## Getting Started

### Installation

Use Anaconda to create a new environment and install the required packages.

```
conda create -n yoloworlddemo python=3.10 -y

conda activate yoloworlddemo

pip install -r requirements.txt
```

### Running the Project

```
python app.py
```
